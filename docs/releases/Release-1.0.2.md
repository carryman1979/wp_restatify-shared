# Release 1.0.2

Version 1.0.2 erweitert das shared package um zentrale Privacy-Utilities und aktualisiert die Release-Dokumentation.

## Highlights

- Shared-Package-Version auf `1.0.2` angehoben
- Neue Utility `PrivacyLegalNotice` fuer wiederverwendbare rechtliche Hinweise bereitgestellt
- README und Release-Dokumentation fuer nachgelagerte Plugin-Releases aktualisiert
- Hotfix ohne Versionssprung dokumentiert: defekte Downstream-Release-Pakete wurden ersetzt, um Shared-Lib-Resolver und Legal-Notice-Abhaengigkeit stabil zu machen

## Kompatibilitaet

- Shared package version: `1.0.2`
- Rueckwaertskompatibel zur 1.0.x-Linie
